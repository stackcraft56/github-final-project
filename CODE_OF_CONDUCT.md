
# Contributor Code of Conduct

## Our Pledge
We pledge to maintain a welcoming, respectful, inclusive, and harassment-free community for all participants.

## Our Standards
Be respectful of differing opinions and experiences. Welcome constructive feedback, show empathy, and contribute professionally. Harassment, insults, threats, discrimination, and publishing private information without permission are unacceptable.

## Enforcement Responsibilities
Project maintainers are responsible for enforcing these standards fairly. They may remove inappropriate contributions or restrict participation when necessary.

## Scope
This code applies to repository discussions, issues, pull requests, and public interactions representing the project.

## Enforcement
Report violations privately to the project maintainers using GitHub repository contact channels. Reports will be reviewed confidentially where possible, and appropriate corrective action will be taken.

## Enforcement Guidelines
1. **Correction:** Explain the inappropriate behavior and request improvement.
2. **Warning:** Issue a formal warning for a violation.
3. **Temporary Ban:** Temporarily restrict participation after serious or repeated violations.
4. **Permanent Ban:** Permanently remove participants for severe or persistent misconduct.
